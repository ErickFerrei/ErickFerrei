### 🎯 Sobre mim

Atuo hoje como **Analista de Processos de TI na Positivo S+**, mapeando, documentando e otimizando fluxos de trabalho — uma base que se conecta diretamente com QA, já que boa parte do trabalho de um analista de testes é entender o processo antes de escrever o primeiro caso de teste.

Estou migrando esse conhecimento para a área de **Qualidade de Software (QA)**, cursando **Análise e Desenvolvimento de Sistemas** e me aprofundando em:

- 🔍 **Testes manuais** (planos de teste, casos de teste, execução, reporte de bugs)
- 🧠 **Lógica de programação** aplicada a testes e automação
- ⚙️ **Back-end**, para entender o sistema de ponta a ponta antes de testá-lo
- 🤝 Trabalho em equipe, atenção aos detalhes e organização — habilidades que já uso no dia a dia como analista de processos
